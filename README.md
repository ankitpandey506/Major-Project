# Emotion-Aware Chatbot 🤖💬

This project is an **Emotion Detection Chatbot** built using **DistilBERT** from Hugging Face.

It detects user emotions from text and responds accordingly.

---

## 🚀 Features

* Emotion classification (6 emotions)
* Context-aware predictions (last 3 messages)
* Transformer-based NLP model
* Simple interactive chatbot

---

## 🧠 Emotions Supported

* Sadness 😢
* Joy 😊
* Love ❤️
* Anger 😡
* Fear 😨
* Surprise 😮

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/emotion-chatbot.git
cd emotion-chatbot
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

---

## 📊 Model

* Model: distilbert-base-uncased
* Dataset: Hugging Face Emotion Dataset
